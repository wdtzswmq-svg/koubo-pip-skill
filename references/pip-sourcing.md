# 画中画素材 SOP：找素材 + 裁中间去水印

## 找素材

- **搜哪**：公开视频平台（抖音 / 小红书 / B站 / 微博视频等），按台词关键词搜。例如台词在讲"某 AI 工具 6 天做了个应用"，就搜该工具的实测视频。
- **挑哪条**：播放量/点赞高的优先（画面质量通常更好）；时长 ≥ PiP 需要的 2–5 秒；画面主体在中间区域（方便裁切）。
- **下回来**：用 yt-dlp（`yt-dlp -f "bv*[height<=1080]" <url>`）；某条被平台风控拦了就换一条同内容的，不硬刚。
- **三重复核**（入片前必做）：① 真的相关——遮住台词看画面，能不能猜出在讲什么；② 调性——不低俗、不竞品广告；③ 不遮挡——PiP 位置不压人脸、字幕、关键信息。

## 裁中间去水印

水印（平台 logo + 作者 ID）一般在**上下两端**，中间是干净主体：

1. `ffprobe -v error -select_streams v:0 -show_entries stream=width,height -of csv=p=0 in.mp4` 看分辨率；
2. 抽一帧看水印带高度（上下通常各 60–120px，按实际量）；
3. 裁：`ffmpeg -i in.mp4 -vf "crop=in_w:in_h-T-B:0:T" -c:a copy mid.mp4`（T=上裁掉，B=下裁掉）；
4. 抽帧验：水印无残留、主体完整、人脸/关键物没被裁掉；
5. 极端情况（水印压在画面中间）：换一条素材，不硬用。

## 备选

实在找不到高相关的公开视频：退回 Pexels / Pixabay 等免费可商用素材库，或用代码绘制的信息动画顶上，**不硬塞不相关的视频**。
